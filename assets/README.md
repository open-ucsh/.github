# Recursos gráficos

Esta carpeta contiene los recursos gráficos compartidos de la organización.

## Archivos actuales

| Archivo | Uso sugerido |
| --- | --- |
| `logo.png` | Logo principal para documentación y perfiles |
| `banner.jpeg` | Banner para el perfil de la organización |
| `logo-ucsh.png` | Logo institucional o variante horizontal |
| `logo-ucsh-footer-yellow.png` | Variante del logo para pie de página |
| `graphic-pregrado.png` | Recurso gráfico asociado a pregrado |

## Convenciones para nuevos archivos

Cuando se agreguen variantes, utilizar nombres descriptivos:

- `logo-primary.svg`: logo principal sobre fondos claros.
- `logo-white.svg`: logo para fondos oscuros.
- `logo-mark.svg`: símbolo sin texto.
- `banner-light.jpeg`: banner para fondos claros.
- `banner-dark.jpeg`: banner para fondos oscuros.
- `favicon.png`: icono para navegadores o aplicaciones.

No reemplaces los archivos actuales ni agregues variantes sin indicar su uso,
fondo recomendado y formato.

Los nombres deben describir el contenido y el contexto de uso. Si se cambia
un nombre después de publicarlo, actualiza también todas sus referencias para
evitar enlaces rotos.

## Reglas de uso

- No deformar, rotar ni recolorear el logo.
- Mantener una separación visual alrededor del logo.
- Preferir SVG para nuevas versiones destinadas a sitios web.
- Usar PNG o JPEG cuando el destino requiera compatibilidad con imágenes
  rasterizadas.

> Esta guía es un borrador editable.
