## 🌱 Flujo de trabajo

1. Actualiza tu copia desde `main`.
2. Crea una rama para tu cambio.
3. Realiza el cambio y verifica que el proyecto funcione.
4. Abre un pull request hacia `main`.

## ✨ Código

* Mantén el código simple, legible y consistente con el proyecto.
* Evita cambios no relacionados con el pull request.
* Elimina código y archivos que ya no se utilicen.
* No incluyas tokens, credenciales ni información privada.

## 🔀 Pull requests

Explica brevemente qué cambia y por qué.

Revisaremos tu pull request y responderemos lo antes posible. Cuando esté listo, cumpla las comprobaciones del proyecto y no tenga conflictos, intentaremos fusionarlo en `main`.

## 💬 Commits

Usamos [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) en inglés.
